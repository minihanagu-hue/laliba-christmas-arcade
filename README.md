# 啦里吧部落・聖誕方塊祭

原創聖誕街機風格的瀏覽器方塊遊戲。米白直立機台、金屬螢幕框、聖誕像素夜景與合成音效，支援鍵盤及能映射為鍵盤輸入的搖桿按鍵。

## 立即遊玩

- GitHub Pages：https://minihanagu-hue.github.io/laliba-christmas-arcade/
- 原有遊玩網站：https://neon-blocks-arcade-yt-1988.minihanagu.chatgpt.site
- 離線單檔版：[下載 NEON-BLOCKS.html](downloads/NEON-BLOCKS.html)（下載檔案後以瀏覽器開啟）

## 玩法

開始前輸入暱稱並選擇模式，再按「開始遊戲」或街機 START 鍵。

| 模式 | 規則 |
| --- | --- |
| 經典模式 | 不限時，堆滿遊戲區結束 |
| 挑戰者 I | 1 分鐘速攻，爭取最高分 |
| 挑戰者 II | 3 分鐘標準，爭取最高分 |
| 挑戰者 III | 5 分鐘耐力，爭取最高分 |

每消除 10 行升級，方塊下降速度隨等級提高。限時挑戰時間到自動結算；提早堆滿也會保存成績。暫停或離開頁面時倒數停止。手動提早結束或重新開始的挑戰標記為中斷，不列入挑戰排行榜。

| 按鍵 | 動作 |

| ← / → | 左右移動 |
| ↓ | 加速下降 |
| ↑ / X | 順時針旋轉 |

## 手機虛擬控制器

手機底部固定雙手操作區：左側是左、右、下方向鍵；右側兩顆圓鍵由左至右為「直接落下」、「旋轉方向」。方向鍵可長按連續操作，旋轉和直落每次按下觸發一次。支援同時按住方向鍵與動作鍵，放開、取消觸控或暫停後會停止連續操作。

小螢幕開始遊戲後會收起裝飾與設定，保留棋盤、計分、倒數及底部按鍵；橫向時按鍵分列兩側。整個觸控區（包含按鍵標籤與空白處）會阻止文字選取、長按搜尋選單與拖曳捲動，並預留手機安全區。

## 計分

一次消除 1／2／3／4 行分別得到 100／300／500／800 分，再乘上當前等級。加速下降每格 1 分，直接落下每格 2 分。連續消行有視覺與聲音提示，不額外改變計分規則。

## 玩家紀錄與聖誕排行榜

- 記錄暱稱、玩法、分數、消行、等級、遊玩時間與完成狀態。
- 經典及三種挑戰時長各自排名，每個暱稱僅保留最佳完成局上榜。
- 同分依消行數、等級、達成時間先後排序。
- 前三名依序搭配原創聖誕老人、馴鹿、雪人頭像；可按「留下大頭照」選擇「相簿上傳」或「拍攝照片」、調整裁切並儲存。手機拍攝使用原生相機入口，優先前鏡頭；電腦端可授權鏡頭、預覽並按「拍下照片」。拍完、關閉視窗或離開頁面會停止鏡頭，不請求麥克風。無相機或權限未開啟時可改用相簿上傳。
- 玩家照片儲存在本機瀏覽器，依暱稱共用；照片旁保留聖誕角色小徽章，可更換或移除。JPG／PNG／WebP 上限 10 MB，儲存時縮成 256 × 256 JPEG。
- 請由玩家本人選擇或取得本人同意後展示。成績 JSON 備份不含照片，換裝置或清除瀏覽器資料後需重新選取原照片。
- 提供 JSON 匯出／合併匯入備份，重複的紀錄 ID 會略過。

**紀錄只存在目前裝置與瀏覽器的 localStorage，不會上傳至 GitHub 或跨裝置同步。** 清除瀏覽器資料、換網址、換瀏覽器或換電腦後不會自動帶入。搬移至 GitHub Pages 前，可先從原網站匯出，再於新網站匯入。請使用暱稱並定期備份。

## 傳說角色・郭大

排行榜左上方展示使用者提供的「郭大」像素圖，作為固定傳說角色與挑戰宣言。郭大區塊不產生虛構玩家或分數；下方前三名與各賽別仍依真實完成局計算。排行榜配色呼應人物的粉紅、深紫黑與亮金，手機會改為緊湊版角色橫幅。

## 畫面與音效

上方「全螢幕展示」適合實體機台。音效預設關閉，按「音效 ON」開啟；頁面下方可調整音量、減弱動態特效及預覽四行消除效果。原創音效透過 Web Audio 即時合成，不需下載音樂檔案。

## 本機執行與測試

這是無依賴、無編譯步驟的靜態網站。可直接開啟 `index.html`，或使用本機靜態伺服器：

```sh
python3 -m http.server 8080
```

瀏覽 `http://localhost:8080`。測試需要 Node.js 18 以上：

```sh
node tests/challenge.test.cjs
node tests/portraits.test.cjs
node tests/camera.test.cjs
node tests/controls.test.cjs
```

測試涵蓋限時結算、暫停續玩、重複結算防止、中斷排除、各時長獨立排行榜、舊紀錄相容及經典不限時。

## GitHub Pages

在儲存庫 **Settings → Pages** 選擇 **Deploy from a branch**，來源為 **main / (root)**。專案含 `.nojekyll`，無需安裝套件或執行建置。網址會依實際帳號及儲存庫名稱決定。

## 實體機台

[直立機台設置概念](setup.html)提供外觀與空間討論。27 吋平面螢幕可裝入原創復古外殼；所有尺寸仍需實機量測、試坐與製作人員確認。網頁造型與概念稿不是施工結構圖。

## 檔案結構

- `index.html`：街機外觀與操作介面
- `controls.js`、`mobile-controls.css`：手機方向鍵、雙圓鍵與長按／多指操作
- `game.js`：方塊、旋轉、碰撞、消行及計分
- `challenge.js`：限時關卡與倒數
- `portraits.js`、`portraits.css`：本機照片選擇、裁切、儲存與名次徽章
- `records.js`：個人紀錄、分類排行榜與備份
- `effects.js`：粒子、消行效果與合成音效
- `market.js`：全螢幕展示控制
- `*.css`、`christmas-pixels.svg`、`avatars/`：原創畫面與角色
- `downloads/NEON-BLOCKS.html`：整合所有素材的離線單檔版
- `tests/`：可重複執行的遊戲邏輯檢查

本專案使用原創繪製圖像、程式生成的像素場景與合成音效；未收錄參考街機照片、商標、原版遊戲圖像或音樂。
